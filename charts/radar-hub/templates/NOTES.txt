LICENSE STATUS
--------------
The license is optional at install. Without one the hub starts but the web UI
shows a license-required screen — set license.key (or license.existingSecret)
and redeploy to activate.

The hub logs license verification at boot. Look for:
  "license verified" — happy path
  "license is expired (warn-only ...)" — past exp; banner shown but writes still work
  "no license configured — hub is blocked ..." — set license.key + redeploy
  "license is invalid ..." — bad signature or claims; check the key you pasted

REPLACING A LICENSE
-------------------
If the license is in your values (license.key), upgrade with the new value; the
upgrade restarts the hub for you:
  helm upgrade {{ .Release.Name }} <chart> -n {{ .Release.Namespace }} --reset-then-reuse-values --set license.key=<JWT>

If it is in your own Secret (license.existingSecret), update the Secret, then
restart the hub so it reads the new file:
  kubectl -n {{ .Release.Namespace }} rollout restart deploy/{{ include "radar-hub.hubName" . }}

Nothing else is interrupted either way.

WHICH LICENSE WINS
------------------
A hub that is NOT air-gapped and holds a cloud-issued, org-linked license
renews it daily and remembers the
result. So there can be two: the one in your values file and the one this hub
fetched. The later expiry wins; on the same expiry, the fetched one wins if the
terms differ, because that is what a mid-period change looks like — buying more
self-hosted clusters keeps the same period end.

This is the one place your values file is not the last word. It is deliberate:
without it, every restart would hand back capacity you had already paid for.
Pasting a genuinely newer key still wins, because a newer license expires later.

AIR-GAPPED INSTALLS
-------------------
Set hub.airGapped=true for a deployment that must not talk to anything outside
your network. It stops the two calls the hub makes on its own initiative: the
hourly check to api.github.com for the latest Radar version, and the daily
license renewal. Pin hub.latestRadarVersion if you still want a version shown;
unpinned, the hub reports none rather than guessing.

An air-gapped license is issued by hand, carries no org id, and is replaced the
way described above. Changing how many clusters it covers is a conversation
with us — there is no self-serve path, by design.
